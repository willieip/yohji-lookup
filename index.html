Is this a complete Yohji archive?

No. It covers records retrieved from the official shop and keeps previously imported records when the catalog is refreshed. Older collections, removed listings, and items sold only elsewhere can be missing. A missing result means this index has no record for that code.

Why can a code appear in Google but not here?

Search engines can find pages across retailers, resale shops, and collectors. Those separate listings do not necessarily belong to one shared database. If a code is missing here, use the source-specific searches to look further.

What counts as a match?

A product code match shares the complete base code, such as HC-C23-100. An exact recorded code also matches the suffix you entered. If only the base matches, the result is labeled “Variant unconfirmed.” A season letter or a similar-looking photo alone does not confirm a match.

How does the index stay up to date?

The source and import date are recorded with the catalog. Each record shows when it was last seen in the source feed. The index is a snapshot; open the original listing for current details and availability.
