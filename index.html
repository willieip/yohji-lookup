Runway / Collection Archives

Some official shop pages connect a product code to a collection and look number. Use that documented reference to find the look in a runway gallery.

  • Official shop lookbooks — selected looks link to garment listings and their product codes.
  • Official POUR HOMME collection archive — browse menswear shows by season.
  • Vogue Runway — compare collections and numbered looks.

Documented example: Jacket HW-J42-832 is listed in the official A/W 2026–27 Look 39. Compare Fall 2026 menswear, Look 39 on Vogue.

The official listing supplies this code-to-look connection. A similar photo or a season letter alone does not confirm a runway match.

This is a snapshot of the official shop’s public product records. It is not a complete historical archive: older collections, removed listings, and items sold only elsewhere can be missing.

A product code match shares the complete base code. An exact recorded code also matches the suffix you entered. If only the base matches, the result is labeled “Variant unconfirmed.”

Search engines can find separate retailer, resale, and collector listings that are not in this database. Use the source searches if a code is missing here.

Refreshes keep previously imported records when they disappear from the live feed. Observation dates are not garment production dates. Open the original listing for current details and availability.
